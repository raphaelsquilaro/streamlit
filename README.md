# 🤖 Primeira Página com Streamlit

Uma pequena aplicação desenvolvida em **Python + Streamlit** como exercício de introdução ao desenvolvimento de interfaces web utilizando Python.

O projeto apresenta uma interface simples para entrada de **peso e altura**, com o objetivo de futuramente realizar o cálculo do **Índice de Massa Corporal (IMC)**.

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido para explorar os primeiros conceitos do **Streamlit**, uma biblioteca Python que permite criar aplicações web interativas utilizando principalmente código Python.

A aplicação atualmente possui:

- 🖥️ Configuração personalizada da página
- 🤖 Interface para uma futura aplicação de IA
- ⚖️ Campo para informar o peso
- 📏 Campo para informar a altura
- 🔘 Botão para realizar o cálculo
- 📋 Área destinada à exibição do resultado

# ⚙️ Instalação

# ▶️ Executando o projeto

Após instalar as dependências, execute:

```bash
streamlit run app.py
```

O Streamlit iniciará um servidor local e disponibilizará a aplicação no navegador.

# 🧮 Funcionamento

A aplicação solicita duas informações:

```text
Peso
  ↓
Altura
  ↓
[ Calcular ]
  ↓
Resultado do IMC
```

A fórmula utilizada para o IMC é:

```text
IMC = peso / altura²
```

Por exemplo:

```text
Peso:   70 kg
Altura: 1.75 m

IMC = 70 / (1.75²)
```
